## 📊 Superstore Sales Dashboard

###  Project Summary

This Power BI dashboard presents a visual analysis of sales data from the *Superstore Sales* dataset. It highlights performance across **regions**, **categories**, and **time periods**, providing stakeholders with clear insights for data-driven decision-making.

---

###  Dataset Details

* **File Used**: Superstore\_Sales.csv
* **Key Fields**: Order Date, Region, Category, Sales, Profit, Quantity

---

###  Tools Used

* **Power BI Desktop**
* **Power Query Editor** (Data Cleaning & Transformation)
* **DAX** (for KPIs and Measures)

---

###  Data Cleaning Process

* Removed nulls and ensured proper data types
* Defined key measures using DAX:

  * `Total Sales`
  * `Total Profit`
  * `Profit Margin`


---

###  Dashboard Components

* **Line Chart** – Sales trend over time (by Month-Year)
* **Bar Chart** – Total Sales by Region
* **Donut Chart** – Sales by Category
* **KPIs** – Total Sales, Total Profit, Profit Margin, 
* **Slicers** – Region and Category filters
* **Theme** – Clean, modern color palette with clear labeling

---

###  Key Insights

1. **West region had the highest total sales overall.**
2. **Technology category contributed the most to total sales, followed by Furniture.**
3. **Sales increased toward the end of each year, suggesting strong Q4 performance.**
4. **South region showed the lowest profit margin despite moderate sales.**

---

###  Objective

To create a **simple, interactive sales dashboard** that allows users to filter by region or category and identify sales trends across months and product lines.
